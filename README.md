# Event RSVPs

A [Chickadee Bandit](https://chickadeebandit.com/app-library/event-rsvps) app.

Create org events and collect RSVPs — who's coming, headcount for catering, send reminders to non-responders, export attendee lists. An event can be shared by link so people outside the household can RSVP without an account.

## Features

- Create events and collect RSVPs from members.
- Live headcount and who's-coming list.
- Send reminders to non-responders only.
- Export the attendee list.

## Install

In your hub, go to **Apps → Install from URL** and paste:

```
https://github.com/firebirdsystems/chickadeebandit-event-rsvps/releases/latest/download/bundle.json
```
